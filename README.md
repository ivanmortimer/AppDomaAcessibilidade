# App Doma Acessibilidade
Trabalho prático final desenvolvido para a disciplina de **"Interação com sensores de smartphones e wearables"** (código **DGT2816**) do curso de graduação tecnológica em *Desenvolvimento Full Stack* da *Universidade Estácio de Sá*.

## Objetivo
Aplicativo Wear OS desenvolvido para a empresa "Doma" com o foco em fornecer assistência e acessibilidade através de saídas de áudio com uso de tecnologia de software Text-To_Speach.

## Tecnologias Utilizadas
* **Programing Language:** Kotlin
* **Minimum Android SDK:** API 30 ("R"; Android 11.0) - Wear OS
* **Build configuration language:** Kotlin DSL (build.gradle.kts)
